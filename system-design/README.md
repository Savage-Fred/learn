# System Design & Distributed Systems Domain

This domain contains curricula, architectural invariants, and scaling rubrics for:
1. Statistics for data analysis & telemetry
2. Rust for high-performance systems
3. Go for concurrent distributed services

## Target Levels
- L4: Standard 3-tier architectures, relational/NoSQL trade-offs, basic caching.
- L5: Multi-region topologies, consensus protocols (Raft/Paxos), cache invalidation, quantitative back-of-the-envelope calculations.
- L6: Multi-year architectural blueprints, catastrophic failure mitigation, protocol design (gRPC/QUIC), organizational alignment (Conway's Law).
