# Privacy Engineering Domain

This domain contains curricula, mathematical privacy proofs, and architectural patterns for:
1. Privacy-Enhancing Technologies (PETs) for AI (confidential computing, homomorphic encryption, MPC)
2. Modern Differential Privacy (DP-SGD, Rényi Differential Privacy, Moments Accountant)

## Target Levels
- L4: Data anonymization techniques, k-anonymity, regulatory compliance translation.
- L5: Differential privacy composition bounds, noise calibration (Laplace/Gaussian), privacy budget accounting.
- L6: Hardware-enforced confidential computing (Apple PCC, Nitro Enclaves), verifiable cryptographic attestation, zero data retention architectures.
