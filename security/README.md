# Security Engineering Domain

This domain contains curricula, threat modeling matrices, and defense invariants for:
1. Modern AuthN/AuthZ (ReBAC, Zanzibar, OAuth2, OIDC)
2. Systematic threat modeling (STRIDE, PASTA, defense-in-depth)
3. Access models for autonomous AI agents (tool sandboxing, capability attenuation, prompt injection defense)

## Target Levels
- L4: OWASP Top 10 mitigation, secure coding, input sanitization, standard auth.
- L5: Fine-grained authorization models, circuit breakers, rate-limiting reverse proxies, zero-trust perimeter.
- L6: MicroVM isolation for untrusted code execution, formal cryptographic attestation, organization-wide threat mitigation.
